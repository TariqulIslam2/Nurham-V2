# Nurham Ltd Company Profile Website

## Project Overview
This project is a company profile website developed using **React.js**. The website showcases the company's services, portfolio, and contact information in a responsive and modern interface. The goal was to create a **user-friendly experience** with smooth navigation and clean UI design.

## My Contributions
- Developed the frontend of the website using **React.js**.
- Created **responsive and modern interfaces** compatible with desktop and mobile devices.
- Implemented smooth navigation and interactive UI components.
- Collaborated with designers to translate visual designs into functional interfaces.
- Ensured a consistent **user experience** across all pages.

## Key Features
- Fully **responsive design** for all devices.
- **Clean and modern UI** with smooth navigation.
- Interactive components for enhanced user engagement.
- Contact form integration and portfolio showcase.

- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Styling:** CSS Modules / Styled Components / Tailwind CSS (choose what you used)
